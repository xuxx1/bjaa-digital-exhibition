# 图片资源说明

## 目录用途

本目录用于存放数字展陈小程序运行所需的图片资源，包括：

- 艺术作品图片
- 展览封面图片
- 展览详情图片
- 用户上传的观展笔记图片


## 资源来源

部分图片资源来源于公开艺术资料及官方网站公开信息，
主要用于数字展陈系统功能展示与开发测试。


## 为什么未上传图片资源

由于项目涉及大量高清艺术作品图片：

- 文件数量较多
- 数据体积较大
- 部分图片存在版权限制

因此 GitHub 仓库仅保留资源目录结构和说明文件，
未上传完整图片数据。


## 本地运行配置

如需完整运行项目，请将对应图片资源放入：


assets/


目录下。

示例：


assets/
│
├── artworks/
│ ├── artwork_001.jpg
│ └── artwork_002.jpg
│
├── exhibitions/
│ ├── exhibition_001.jpg
│ └── exhibition_002.jpg
│
└── user_notes/
└── upload_images/



## 数据格式

系统通过资源路径加载图片：

示例：

```json
{
    "title": "作品名称",
    "author": "作者",
    "image": "/assets/artworks/example.jpg"
}

实际运行时需要保证图片路径与数据文件保持一致。
